# 操作日志规则

适用于本项目的所有操作日志记录。

---

## 核心原则

**所有 AI 操作**（包括但不限于代码修改、文件操作、配置变更、内容创作、数据分析、问答记录等）必须以**追加方式**记录到 `operateLog.md` 文件中，**禁止覆盖**已有内容。

本规则适用于 **所有类型的 AI 助手操作**。

---

## 1. 记录时机

以下操作完成后，必须立即记录到 `operateLog.md`：

### 文件操作类
- ✅ 创建新文件
- ✅ 修改现有文件
- ✅ 删除文件
- ✅ 移动或重命名文件

### 配置变更类
- ✅ 重大配置变更
- ✅ 数据库结构变更
- ✅ 部署操作
- ✅ 环境变量修改

### 内容创作类
- ✅ 撰写文案或文章
- ✅ 生成代码或脚本
- ✅ 数据分析报告
- ✅ 方案策划文档

### 其他操作
- ✅ 任何对项目有影响的决策或建议
- ✅ 重要问答记录
- ✅ 问题诊断过程
- ✅ Bug 修复过程

## 2. 记录格式

每次追加记录应遵循以下格式：

```markdown
## YYYY-MM-DD HH:mm:ss 操作简述

操作描述

---
```

### 完整示例
```markdown
## 2026-02-28 12:59:01 添加用户认证功能

为后端 API 添加 JWT 用户认证中间件

涉及文件：
- security.py
- main.py

新增功能：
- 白名单用户验证
- JWT 令牌验证
- 用户信息提取

---
```

### 简化示例
```markdown
## 2026-02-28 15:30:45 修复登录接口 Bug

修复登录接口在密码错误时返回状态码不正确的问题

修改：controllers/authController.js
变更：错误响应状态码从 200 改为 401

---
```

## 4. 追加模式要求

### 必须遵守的规则
- ✅ **只使用追加模式**：每次添加新记录到文件末尾
- ✅ **不删除已有记录**
- ✅ **不修改已有记录**
- ✅ **保持历史记录的完整性**
- ✅ **使用换行符分隔每条记录**

### 违规示例
```bash
# ❌ 错误 - 覆盖文件
echo "New record" > operateLog.md

# ❌ 错误 - 删除旧记录
echo "" > operateLog.md

# ❌ 错误 - 修改已有内容
# （手动编辑删除旧记录）
```

### 正确示例
```bash
# ✅ 正确 - 追加记录
echo "New record" >> operateLog.md

# ✅ 正确 - 在 Python 中追加
with open('operateLog.md', 'a', encoding='utf-8') as f:
    f.write('New record\n')
```

## 6. 记录内容要求

### 必须包含的信息
- ✅ **时间**：操作完成时间
- ✅ **操作简述**：一句话概括操作内容
- ✅ **详细描述**：操作的具体内容和目的

### 建议包含的信息
- 📝 **涉及文件**：修改或创建的文件列表
- 📝 **变更内容**：具体的修改内容
- 📝 **原因说明**：为什么要进行此操作

### 操作类型标识
```markdown
## YYYY-MM-DD HH:mm:ss [类型] 操作简述

类型可以是：
- [新增] - 新增功能或文件
- [修改] - 修改现有功能
- [修复] - 修复 Bug
- [删除] - 删除功能或文件
- [优化] - 优化性能或代码
- [文档] - 文档更新
- [配置] - 配置变更
- [部署] - 部署操作
```

## 8. 自动记录建议

### 在 Python 代码中自动记录
```python
from datetime import datetime

def log_operation(operation: str, description: str, files: list = None):
    """自动记录操作到 operateLog.md"""
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")

    record = f"## {timestamp} {operation}\n\n"
    record += f"{description}\n\n"

    if files:
        record += "涉及文件：\n"
        for file in files:
            record += f"- {file}\n"

    record += "\n---\n"

    with open('operateLog.md', 'a', encoding='utf-8') as f:
        f.write(record)

# 使用示例
log_operation(
    operation="添加用户认证功能",
    description="为后端 API 添加 JWT 用户认证中间件",
    files=[
        "security.py",
        "main.py"
    ]
)
```
